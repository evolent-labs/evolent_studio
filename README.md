<h1 align="center">Evolent Studio</h1>

A photo studio for FiveM. Admins take clean, cut-out pictures in game, and other resources show them in their menus, phone apps and websites.

Vehicles are photographed once per model and shown in every owner's own paint. Each car looks like the one the player owns, without a picture for every colour. Players never send pictures, so they cannot fake them, and every photo is the same quality.

## Features

- A studio menu with live preview: camera angles, light, backgrounds, shadows, reflections, texts and logos.
- Photos on a green screen, cut out automatically, or in a real place on the map.
- A queue that photographs every vehicle on the server in one go.
- Saved styles, so every photo for a garage, dealership or Discord looks the same.
- Exports for other resources, and links through Fivemanage, Discord or the server folder.

## Requirements

- ox_lib
- oxmysql
- screencapture or screenshot-basic
